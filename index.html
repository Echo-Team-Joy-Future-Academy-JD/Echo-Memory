Overview

World models must both follow and remember.

Action-conditioned world models generate video chunk by chunk from a first frame, text prompt, and camera-action sequence. Local frames can look plausible while the scene or salient object silently changes once the camera leaves and returns. Echo-Memory isolates that memory failure instead of introducing another bespoke module.

  • Controlled comparison. We fix the video DiT backbone, data interface, relative-RT actions, sampler, and evaluation code path, and vary only how history is stored and read.
  • Unified training. Every row uses the same single-stage schedule, optimizer, segment length, and in-training replay diagnostics on a shared held-out pool.
  • Unified evaluation. Replay, in-domain loop closure, and open-domain return are reported as a stacked bundle rather than a single scalar.
  • Factorized design space. The matrix separates capacity, compression, read-out, and recurrence instead of mixing them across unrelated system changes.

Building the Unified Protocol

One training path and one evaluation path for every memory row.

Existing memory papers are hard to compare because gains are entangled with backbone, training recipe, retrieval, and evaluation differences. Echo-Memory treats those pieces as constants and promotes only the memory profile across rows.

What stays fixed?

All variants share a pre-trained video diffusion transformer with per-frame VAE context, rectified-flow training on target frames only, suffix context placement, a 10% overlap-drop policy, and the same field-of-view retriever over historical frames. Camera actions are 12-dimensional relative RTs in the first-frame reference; trajectories are constructed before generation so replay remains a test of control and memory, not post-hoc alignment.

How do we train every row?

Training uses the Context-as-Memory dataset: 81-frame segments at 352×640 with per-frame poses and prompts. For each segment, the model receives the target chunk plus K historical observations retrieved from pre-computed FOV overlap labels keyed on the segment mid-frame. We deliberately avoid multi-stage curricula so that differences across rows read as memory effects rather than schedule artifacts.

Flow-matching loss alone is a weak progress signal for action world models—two runs can look similar on the loss while diverging on return trajectories. We therefore run replay sampling during training on a fixed held-out first-frame pool, using the same generation procedure as final evaluation. Sampled videos become an early monitor for boundary continuity, identity preservation, and action–visual alignment before the full three-branch bundle is computed.

What prevents hidden protocol changes?

Every checkpoint is evaluated only if the run passes the same hard-fail checks used in the paper:

  • Context handling and noise levels match between training and inference.
  • Context budget K matches between training and inference.
  • Camera-action weights are loaded before any evaluation branch runs.
  • Train and eval use the same reference-frame rule for FOV retrieval.
  • State-Space and Compression hybrid rows obey explicit mutual-exclusion rules.

How is evaluation constructed?

Evaluation is built on the same generation stack as training replay: identical retriever, relative-RT constructor, memory write/read profile, and chunk length. We separate two problems that are often collapsed— following an observed trajectory versus remembering a scene after the camera returns—and report three pose settings on that shared path.

  • Replay drives the dataset GT trajectory for multiple chunks and reports PSNR / SSIM / LPIPS. It acts like a cheap pretraining monitor (analogous to perplexity), not the final memory score.
  • In-domain loop closure uses dataset-backed samples with a 180° return loop, reporting paired PSNR and VLM verification where pixel correspondences exist.
  • Open-domain return uses held-out edited first frames with a shorter 45° revisit probe scored by VLM when no GT trajectory is available.

Replay, revisit PSNR, VLM scores, and qualitative panels are reported together. When the branches disagree—as they routinely do—the rank shift is itself evidence that replay fidelity is not a sufficient proxy for remembering a world.

Memory Design Space

Only the write–read profile changes across rows.

Every variant receives the same evidence set from FOV retrieval; the memory profile π decides how evidence is written into state and exposed back to the denoiser. The four families in our matrix are Context (raw capacity), Compression (token budget), Spatial (summaries and read-out), and State-Space (block-wise recurrence).

Three-Branch Evaluation

Each branch answers a different failure mode.

The taxonomy below is the evaluation half of the unified protocol: same models, same sampler, different camera-pose settings and metric bundles.

Replay

Long-horizon GT-trajectory synthesis over multiple 81-frame chunks. Measures whether the generator can follow observed motion with stable frame quality. Strong replay does not imply strong return memory.

In-domain revisit

Symmetric yaw loops on dataset samples with GT poses and images. PSNR at mirrored trajectory positions tests visual loop closure; VLM scoring catches identity and layout drift pixels may miss.

Open-domain probe

Held-out first frames with Qwen-edited identity anchors and a controlled 45° return. Without pixel-aligned GT, semantic VLM verification is the primary signal for whether the same object survives.

Qualitative Evidence

Return probes make identity drift visible.

After the unified metrics are computed, we inspect representative sweeps and edited first frames. The question is not local plausibility but whether the same object and scene are still there when the camera comes back.

Main Conclusions

Replay quality is not memory quality.

Under the unified protocol above, the central result is a metric inversion: methods strong under GT replay can fail on return, while designs with weaker replay fidelity can preserve the world better.

01

Raw context is the capacity baseline.

Increasing raw history improves open-domain return far more than it improves replay metrics. Revisit consistency scales with available evidence, not pixel fidelity alone.

02

Compact memory can lose the object.

Spatial summaries and hybrid compression are efficient, but they can discard the salient identity evidence needed when the camera leaves and returns.

03

Structured recurrence is the strongest return bias.

Block-wise State-Space memory reaches the best open-domain return score in our matrix despite lower replay fidelity.
