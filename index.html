When the camera leaves and returns, which memory keeps the same world instead of a plausible but different scene?

Overview

One backbone, one protocol — only memory changes.

Echo-Memory fixes the action-to-video stack and varies only how history is stored and read back. Replay, in-domain loop closure, and open-domain return are reported together so metric rank shifts stay visible.

Memory Design

Context · Compression · Spatial · State-Space

  • Context — raw history capacity (K = 1 / 5 / 20).
  • Compression — compact temporal evidence (r = 4).
  • Spatial — explicit spatial read/write state.
  • State-Space — block-wise recurrent memory.

Evaluation

Replay · In-domain revisit · Open-domain return

  • Replay — follow GT trajectories (PSNR / SSIM / LPIPS).
  • In-domain revisit — 180° loop closure with GT poses.
  • Open-domain return — edited first frames + 45° VLM probe.

Qualitative Evidence

Return probes expose identity drift.

Main Conclusions

Replay quality ≠ memory quality.

  • Raw context scales open-domain return more than replay metrics.
  • Compact memory can drop salient identity when the camera returns.
  • Block-wise SSM gives the strongest open-domain return in our matrix.
